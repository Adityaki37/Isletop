# Original Island Table assets

All 271 game SVG images and 250 region badges are generated from original shapes and compositions in scripts/generate-original-assets.mjs. All 48 WAV effects are synthesized from original oscillators, envelopes and note sequences in the same generator. No downloaded image, font or audio file is used as an input. Artwork uses system fonts. Countries use original country-code badges instead of downloaded flag artwork.
